# Мастер сценариев

Цифровой стол для настольных кампаний с механикой правления в духе Reigns: карты с двумя вариантами, шкалы с кризисами на обоих краях, флаги-последствия, отложенные карты, сцены, случайные события и голосование игроков с телефонов. Сюжет в приложение не встроен: всё — шкалы, колоды, карты, сцены, персонажи, оформление — задаётся одним JSON-файлом сценария.

Приложение ведёт колоду, шкалы и память выборов. Сцены играются вживую, а их исход Мастер вводит на пульте.

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # статическая сборка в dist/
npm test          # тесты движка
```

Бэкенд не нужен. Партия автосохраняется в браузере (IndexedDB) после каждого действия. После первой загрузки сайт работает оффлайн.

## Как играть

1. Откройте сайт и загрузите сценарий: **⬆ Загрузить сценарий (JSON)**, перетащите файл в окно, вставьте JSON или дайте прямую ссылку (например, «Raw» на GitHub или gist). Чтобы посмотреть, как всё устроено, нажмите **Открыть пример**.
2. **Стол → 🃏 Автосборка** (или соберите очередь из пула кнопками `↳` / `＋`), при желании **🎲 Бросить** случайные события, затем **▶ Начать раунд**.
3. Клавиша **`** (Ё) переключает «пульт / вид игроков». **⧉ Окно игроков** открывает отдельное окно для ТВ. **📡 Открыть комнату** даёт код и QR для телефонов.
4. Сцены и кризисы Мастер закрывает на пульте: заготовленный исход или «Свой исход». После последней карты раунда — итоги и сборка следующего.

Горячие клавиши: `` ` ``/`Ё` — вид игроков, `Ctrl+Z` — отмена (полная история), `H` — скрыть экран игроков.

## Формат сценария

Минимальный сценарий — шкалы и карты:

```json
{
  "title": "Королевство",
  "tracks": [
    { "id": "people", "name": "Народ", "icon": "🧑‍🌾" },
    { "id": "gold", "name": "Казна", "icon": "💰" }
  ],
  "cards": [
    {
      "id": "tax",
      "title": "Подати",
      "deck": "daily",
      "face": "Сборщики спрашивают, поднимать ли подати.",
      "left":  { "label": "Поднять",   "effects": [{ "type": "track", "track": "gold", "delta": 2 }, { "type": "track", "track": "people", "delta": -2 }] },
      "right": { "label": "Не трогать", "effects": [{ "type": "track", "track": "people", "delta": 1 }] }
    }
  ],
  "scenes": []
}
```

Полный пример со всеми возможностями — [`scenarios/example.json`](scenarios/example.json); его же можно скачать с сайта кнопкой «Скачать пример как шаблон». Большой реальный сценарий — [`scenarios/rouen.json`](scenarios/rouen.json).

### Верхний уровень

| Поле | Обяз. | Что это |
|---|---|---|
| `title` | | Название сценария |
| `meta` | | Оформление: `brand` (шапка, например «⚜ Руан»), `splash` (текст заставки при скрытом экране), `round` (как называется раунд, по умолчанию «Интерлюдия») |
| `tracks` | да | Шкалы, см. ниже. Все шкалы — 0–10, опасные зоны 0–2 и 8–10 |
| `decks` | | Колоды, см. ниже. Если не указаны — создаются по полю `deck` карт |
| `cards` | да | Карты |
| `scenes` | | Сцены (узлы, кризисы) |
| `characters` | | Персонажи игроков `[{id, name}]` — их выбирают на телефонах; по умолчанию «Игрок 1–3» |
| `population` | | Механика населения и ёмкости, см. ниже |
| `plotTimers` | | Таймеры сюжета `[{id, title, max}]` — «стадия N из max» |
| `calendar` | | `seasons` (список сезонов), `weeksPerSeason` (по умолчанию 13) |
| `gmReference` | | Справка мастера (Markdown): NPC, открытые вопросы, тон |
| `eventRules` | | Правила случайных событий (Markdown) — показываются у кнопки броска |

### Шкалы `tracks[]`

`{ "id", "name", "icon", "start": 5, "crisis": true, "description" }`. `crisis: false` — шкала без кризисов (например, ёмкость). `description` (Markdown) игрок видит, нажав на шкалу. `id` `population` зарезервирован.

### Колоды `decks[]`

`{ "id", "name", "icon", "color", "role", "timer" }`. `role` определяет, как колода участвует в автосборке:

| role | Как используется |
|---|---|
| `routine` | Рутина: квота автосборки; отсюда же берётся карта «цены времени» при «Разбираемся лично» |
| `line` | Сюжетные линии (по умолчанию) |
| `mirror` | Личное/рефлексия, квота «зеркала» |
| `omen` | Знамения, обычно без выбора |
| `event` | Случайные события — только через бросок |
| `other` | В автосборку не попадает |

`timer: null` — у карт колоды нет таймера; число — свой таймер в секундах.

### Карта `cards[]`

| Поле | Что это |
|---|---|
| `id`, `title`, `deck`, `face` | Обязательные. `face` — текст для игроков (Markdown) |
| `left`, `right` | Варианты `{label, effects, gmNote, opensScene}`. Без обоих вариантов — карта «принять к сведению» |
| `timeOfDay`, `image` | Подпись времени, иллюстрация |
| `gmNote` | Блок «🎭 Мастеру» (Markdown), игрокам не уходит |
| `requires` | Условия попадания в пул |
| `escalation` | id заготовленной сцены для «Разбираемся лично» |
| `timer` | Секунды или `null` |
| `oneShot` | `false` — карта может повторяться |
| `interlude` | Рекомендованный раунд (автосборка ставит такие карты вперёд) |
| `tags` | Произвольные метки |
| `idleDefault` | `"left"`/`"right"` — «худший» вариант при истечении таймера |
| `owner` | 👤 Личная: голосует только этот персонаж |
| `contested` | 👥 Спорная: `{ "between": [a, b], "tiebreaker": c }` |
| `secret` | 🔒 Секретная: содержимое уходит только на телефон адресата |
| `event` | Случайное событие: `{tier, roll, immediate, attracts, bestFor, success, failure, successEffects, failureEffects}` |

**Эффекты:** `track` (`track`, `delta`, `temporary: true` — до конца раунда), `population` (`delta`), `setFlag`/`clearFlag` (`flag`), `timer` (`id`, `delta`), `addCard` (`card`, `delay: {cards} | {interludes}`), `removeCard` (`card`), `note` (`text` — только в журнал Мастера).

**Условия:** `{flag}`, `{notFlag}`, `{track, op, value}` (в том числе `track: "population"`), `{timer, op, value}`, `{anyOf: [...]}`, `{allOf: [...]}`. Список условий — это «все сразу».

### Сцены `scenes[]`

`{ "id", "title", "playerText", "gmNotes", "outcomes": [Option, Option], "crisisOf": {"track", "edge": "low"|"high"}, "owner" }`. Сцена с `crisisOf` открывается, когда шкала доходит до 0 или 10; после исхода шкала откатывается к 2 или 8. Если кризисной сцены нет, будет заглушка.

### Население `population`

`{ "label": "Население", "start": 3, "capacityTrack": "capacity", "overflow": { "track": "masquerade", "delta": -1, "message": "…", "conflictDeck": "night", "conflictTag": "capacity_conflict" } }`. Если в конце раунда население больше значения шкалы `capacityTrack`, применяется `overflow`: сдвиг шкалы, сообщение в хронику и карта-конфликт в следующий раунд.

## Механики

- **👤 Личные, 👥 спорные, 🔒 секретные карты.** Голосует только адресат. На спорной карте решают двое; если разошлись, открывается голос третьего; если время вышло — решает Мастер. Секретная карта уходит только на телефон адресата по личному зашифрованному каналу; общий экран и хроника видят «Личная карта (имя)».
- **«Разбираемся лично»** есть на любой карте. Цена — время: +1 карта рутины и −1 к шкале на выбор Мастера. Без заготовленной сцены пульт предлагает «Успех» (лучше обоих вариантов) и «Провал» (хуже обоих); у событий — исходы из их описания. Всегда доступен «Свой исход».
- **🎲 Случайные события** (колода с ролью `event`): d100 с модификаторами (+3 за шкалу в опасной зоне, +5 за кризис в прошлом раунде, −10 за два и более личных вмешательства), затем кубик уровня. Средние и тяжёлые — один раз за партию (повтор сдвигается на ближайшее несыгранное), катастрофы — тоже, мягкие повторяются. События, притянутые флагами (`attracts`), можно взять вместо выпавшего. `immediate` — первой картой.
- **Таймер, кризисы, отложенные карты, отмена** — как в ТЗ: таймер по истечении ставит паузу, выбирает случайно или «худший» вариант (настройка); кризисы идут в очередь; `addCard` с задержкой; полная история отмен.

## Игроки со своих телефонов

1. На пульте нажмите **📡 Открыть комнату** — появятся код, ссылка и QR.
2. Игроки сканируют QR, выбирают персонажа из `characters` и голосуют. Режимы: голосование большинством, ведущий игрок, «кто первый».
3. Связь идёт через бесплатный публичный MQTT-ретранслятор по защищённому WebSocket, трафик шифруется ключом из кода комнаты. Свой ретранслятор — переменная `MQTT_URL` в настройках Actions.

Пульт открывайте с опубликованного сайта, а не с `localhost`, иначе QR поведёт телефоны не туда.

## Сохранения и совместимость

- **Настройки → Экспорт / Импорт сохранения** — один JSON: сценарий, шкалы, флаги, хроника и история отмен.
- **Хроника → Markdown** для игроков и полный (для Мастера).
- **Старые файлы.** Сценарии и сохранения в старом формате (без `tracks`/`decks`) загружаются как раньше: приложение подставляет шкалы и колоды «Руана».

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` на каждом пуше гоняет тесты и сборку, а основную ветку публикует на Pages (**Settings → Pages → Source: GitHub Actions**). Для приватного репозитория нужен платный план и переменная `DEPLOY_PAGES=true`.

Сценарии в сборку сайта не входят — только нейтральный пример. Если не хотите, чтобы сюжет лежал в открытом репозитории, держите свои JSON вне его: загружайте файлом или по ссылке на приватный gist.

## Устройство

- `src/engine/` — движок без UI: `scenario.ts` (шкалы, колоды, оформление), `validate.ts` (импорт с понятными ошибками), `game.ts` (правила), `build.ts` (автосборка), `events.ts` (броски), `votes.ts` (кто решает), `public.ts` (что видят игроки), `journal.ts` (Markdown). Тесты — `*.test.ts`.
- `src/store.ts` — партия + история отмен, автосохранение.
- `src/net/` — комната для телефонов (MQTT, шифрование, личный канал для секретных карт).
- `src/ui/` — экран игроков (получает только публичную проекцию), пульт Мастера, загрузка сценария.
- `scenarios/` — пример и сценарий «Руан».
