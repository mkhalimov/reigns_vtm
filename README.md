# Руан — управление доменом

Цифровой стол для режима правления доменом в хронике VtM 5e «Dawn». Механика в духе Reigns: карты с двумя вариантами, четыре двусторонние шкалы, флаги-последствия, эскалация карт в сцены. Приложение ведёт колоду, шкалы и память выборов, а сцены играются вживую.

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # статическая сборка в dist/ (можно открыть через любой статический сервер)
npm test          # тесты движка (критерии приёмки из ТЗ)
```

Бэкенд не нужен. Партия автосохраняется в IndexedDB после каждого действия. После первой загрузки собранная версия работает оффлайн (service worker).

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` на каждом пуше гоняет тесты и сборку, а основную ветку публикует на GitHub Pages.

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. Репозиторий должен быть публичным: на бесплатном плане Pages для приватных не работает. С платным планом оставьте его приватным и задайте переменную `DEPLOY_PAGES=true` (**Settings → Secrets and variables → Actions → Variables**).
3. После пуша сайт появится по адресу `https://<логин>.github.io/reigns_vtm/`.

**Про спойлеры.** Телефоны игроков загружают только свой маленький бандл: колоды, заметок и кода пульта в нём нет. Но в публичном репозитории файл `data/rouen-deck.json` может открыть любой, кто знает адрес. Чтобы колода не лежала в открытом доступе, держите репозиторий приватным и публикуйте на Cloudflare Pages или Netlify: оба бесплатно собирают сайт из приватного GitHub-репозитория (команда сборки `npm run build`, папка `dist`).

## Игроки со своих телефонов

1. На пульте в правой колонке нажмите **📡 Открыть комнату**. Появятся код, ссылка и QR.
2. Игроки сканируют QR (или вводят код на `…/#/join`) и выбирают своего персонажа из списка колоды (`characters`: Магнус, Ева, Борис). Занятого персонажа выбрать нельзя, пока его игрок на связи. Если игрок сменил телефон, освободите персонажа крестиком на пульте.
3. **Кто решает** (выбирается на пульте):
   - **голосование:** решение принимается, когда проголосуют все подключённые; большинство побеждает, при ничьей решает Рассказчик;
   - **ведущий игрок:** решает отмеченный на пульте персонаж, голоса остальных видны как совет;
   - **кто первый:** решает первый нажавший.
4. Голос можно сменить или снять повторным нажатием. Когда время вышло, считаются поданные голоса; если голосов нет, срабатывает настройка таймера. Рассказчик всегда может выбрать за игроков.

Как это устроено: партия живёт только в браузере Рассказчика. Телефоны обмениваются с ним сообщениями через бесплатный публичный MQTT-ретранслятор по защищённому WebSocket, как обычный сайт, поэтому работает через мобильный интернет, NAT и VPN. Порядок ретрансляторов: `broker.emqx.io`, `broker.hivemq.com`, `test.mosquitto.org`. Пульт берёт первый доступный, его номер зашит в QR, а телефон при вводе кода вручную перебирает все. Трафик шифруется AES-GCM ключом из кода комнаты, так что ретранслятор видит только шифротекст. Игрокам уходит только публичная проекция: карта без эффектов, шкалы, хроника «что решили» и голоса. Свой ретранслятор можно задать переменной `MQTT_URL` (**Settings → Secrets and variables → Actions → Variables**).

Комната переживает перезагрузку страницы Рассказчика, телефоны переподключаются сами. Пульт должен быть открыт с опубликованного сайта, а не с `localhost`: иначе ссылка в QR поведёт игроков на их собственный компьютер.

## Как играть

1. **Стол → Автосборка** (или соберите очередь вручную из пула кнопками `↳` / `＋`), при необходимости поправьте порядок перетаскиванием, затем нажмите **Начать интерлюдию**.
2. Клавиша **`** (она же **Ё**) переключает «пульт / вид игроков». Второй вариант — **⧉ Окно игроков**: откроется отдельное окно для ТВ или проектора. Оно получает только публичную проекцию состояния.
3. Игроки выбирают ◀/▶ кнопками, свайпом (на тач-экранах) или стрелками ←/→. Кнопка **Разбираемся лично** видна, только если у карты есть сцена или GM разрешил эскалацию.
4. Сцены и кризисы GM закрывает на пульте: заготовленный исход или **Свой исход**.
5. После последней карты открываются итоги, затем **Собрать интерлюдию N+1**.

Горячие клавиши: `` ` ``/`Ё` — вид игроков, `Ctrl+Z` — отмена (полная история), `H` — скрыть экран игроков (заставка).

## Колода «Руан»

Встроенная колода [`data/rouen-deck.json`](data/rouen-deck.json) переведена из документов «Руан — колода на игру» и её мастерской версии. Тексты карт для игроков, время суток и полные блоки «🎭 Мастеру» (суть, персонажи, как подать, последствия ◀/▶, эскалация, связи) взяты из мастерской версии. Колода: 49 карт трёх интерлюдий, 11 сцен (А–Л), 8 кризисов. Новая партия начинается с неё. Если в браузере уже сохранена партия с другой колодой, её можно загрузить через **Колода → ⚜ Встроенная колода «Руан»**.

Как переводились колоды документа: ДВОР → `court`, ДЕ РУАН → `deruan`, НОЧЬ → `night`, ВОРОТА → `gates`, ЗЕРКАЛО → `mirror`, ЗНАМЕНИЕ → `omen`, ГОРОД (и карты 5–6 без колоды) → `routine`. Двойные колоды (3, 24, 42) отнесены к первой из двух, карта 38 — к `night`. Флаги сохранены как в документе, по-русски. ⚡ без названной сцены — это `"escalation": true`: сцена импровизируется, исход GM вводит через «Свой исход». У сцен для карт 23, 40, 47 и у кризисов в документе нет заготовленных исходов, поэтому исходы для них тоже вводятся вручную. Сцены Ж, З и Л ни к какой карте не привязаны, GM открывает их на пульте («Открыть сцену»).

## Формат колоды

Колода — это JSON вида `{ "title", "cards": [...], "scenes": [...], "plotTimers": [...] }`. Поля описаны в ТЗ (раздел 4), пример лежит в [`data/demo-deck.json`](data/demo-deck.json). Импорт: **Колода → Импорт из файла** или вставка JSON. Ошибки выводятся с номером и id карты, например `Карта #7 «c07»: неизвестная колода "nigth"`.

Расширения сверх ТЗ:

| Поле | Где | Назначение |
|---|---|---|
| `idleDefault: "left" \| "right"` | карта | «Худший» вариант при истечении таймера (настройка «по истечении → худший») |
| `{type:"population", delta}` | эффект | Меняет счётчик «Население» (5.6) |
| `{track:"population", op, value}` | условие | Условие на население |
| тег `capacity_conflict` | карта `night` | Карта-конфликт, которую приложение добавит при переполнении Ёмкости |
| `plotTimers: [{id, title, max}]` | колода | Таймеры сюжета, «стадия N из max» |
| `characters: [{id, name}]` | колода | Персонажи, которых выбирают игроки на телефонах (по умолчанию «Игрок 1–3») |
| `start: {population, tracks}` | колода | Стартовые значения (в «Руане» население 3 — сама котерия) |
| `trackInfo: {шкала: текст}` | колода | Описание шкалы, которое игрок видит, нажав на неё (Markdown) |
| `gmReference` | колода | Справка мастера: NPC, открытые решения, тон интерлюдий (вкладка «Колода» и экран сборки) |
| `crisisOf: {track, edge}` | сцена | Кризисная сцена шкалы; если сцены нет, будет заглушка |
| `escalation: true` | карта | Эскалация без заготовленной сцены |
| карта без `left`/`right` в любой колоде | карта | «Принять к сведению» (напр. «Срок первого отчёта») |

`addCard.delay`: `{cards: N}` — через N карт (без `delay` — следующей картой); `{interludes: N}` — обязательно в интерлюдию «текущая + N»; `{interludes: 0}` — в конец текущей.

## Устройство

- `src/engine/` — чистый движок без UI: типы, валидация импорта, условия и эффекты, кризисы, эскалация, автосборка, итоги, публичная проекция (`public.ts`), экспорт журнала в Markdown. Все правила покрыты тестами в `engine.test.ts`.
- `src/store.ts` — единый стор: колода + состояние + стек истории для undo, автосохранение.
- `src/ui/PlayerScreen.tsx` — экран игроков. Принимает **только** `PublicState`: флагов, заметок, эффектов и пула в нём нет даже в памяти компонента.
- `src/ui/gm/` — пульт, сцены, итоги, журнал, колода, настройки.

## Что не входит в MVP

Визуальный редактор карт (сейчас есть просмотр, предпросмотр глазами игроков и импорт/экспорт JSON) и звук.
