# Руан — управление доменом

Цифровой стол для режима правления доменом в хронике VtM 5e «Dawn». Механика в духе Reigns: карты с двумя вариантами, четыре двусторонние шкалы, флаги-последствия, эскалация карт в сцены. Приложение ведёт колоду, шкалы и память выборов, а сцены играются вживую.

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # статическая сборка в dist/ (можно открыть через любой статический сервер)
npm test          # тесты движка (критерии приёмки из ТЗ)
```

Бэкенд не нужен. Партия автосохраняется в IndexedDB после каждого действия. После первой загрузки собранная версия работает оффлайн (service worker).

## Как играть

1. **Стол → Автосборка** (или соберите очередь вручную из пула кнопками `↳` / `＋`), при необходимости поправьте порядок перетаскиванием, затем нажмите **Начать интерлюдию**.
2. Клавиша **`** (она же **Ё**) переключает «пульт / вид игроков». Второй вариант — **⧉ Окно игроков**: откроется отдельное окно для ТВ или проектора. Оно получает только публичную проекцию состояния.
3. Игроки выбирают ◀/▶ кнопками, свайпом (на тач-экранах) или стрелками ←/→. Кнопка **Разбираемся лично** видна, только если у карты есть сцена или GM разрешил эскалацию.
4. Сцены и кризисы GM закрывает на пульте: заготовленный исход или **Свой исход**.
5. После последней карты открываются итоги, затем **Собрать интерлюдию N+1**.

Горячие клавиши: `` ` ``/`Ё` — вид игроков, `Ctrl+Z` — отмена (полная история), `H` — скрыть экран игроков (заставка).

## Колода «Руан»

Встроенная колода [`data/rouen-deck.json`](data/rouen-deck.json) переведена из документа «Руан — колода на игру»: 49 карт трёх интерлюдий, 11 сцен (А–Л), 8 кризисов. Новая партия начинается с неё. Если в браузере уже сохранена партия с другой колодой, её можно загрузить через **Колода → ⚜ Встроенная колода «Руан»**.

Как переводились колоды документа: ДВОР → `court`, ДЕ РУАН → `deruan`, НОЧЬ → `night`, ВОРОТА → `gates`, ЗЕРКАЛО → `mirror`, ЗНАМЕНИЕ → `omen`, ГОРОД (и карты 5–6 без колоды) → `routine`. Двойные колоды (3, 24, 42) отнесены к первой из двух, карта 38 — к `night`. Флаги сохранены как в документе, по-русски. ⚡ без названной сцены — это `"escalation": true`: сцена импровизируется, исход GM вводит через «Свой исход». У сцен для карт 23, 40, 47 и у кризисов в документе нет заготовленных исходов, поэтому исходы для них тоже вводятся вручную. Сцены Ж, З и Л ни к какой карте не привязаны, GM открывает их на пульте («Открыть сцену»).

## Формат колоды

Колода — это JSON вида `{ "title", "cards": [...], "scenes": [...], "plotTimers": [...] }`. Поля описаны в ТЗ (раздел 4), пример лежит в [`data/demo-deck.json`](data/demo-deck.json). Импорт: **Колода → Импорт из файла** или вставка JSON. Ошибки выводятся с номером и id карты, например `Карта #7 «c07»: неизвестная колода "nigth"`.

Расширения сверх ТЗ:

| Поле | Где | Назначение |
|---|---|---|
| `idleDefault: "left" \| "right"` | карта | «Худший» вариант при истечении таймера (настройка «по истечении → худший») |
| `{type:"population", delta}` | эффект | Меняет счётчик «Население» (5.6) |
| `{track:"population", op, value}` | условие | Условие на население |
| тег `capacity_conflict` | карта `night` | Карта-конфликт, которую приложение добавит при переполнении Ёмкости |
| `plotTimers: [{id, title, max}]` | колода | Таймеры сюжета, «стадия N из max» |
| `crisisOf: {track, edge}` | сцена | Кризисная сцена шкалы; если сцены нет, будет заглушка |
| `escalation: true` | карта | Эскалация без заготовленной сцены |
| карта без `left`/`right` в любой колоде | карта | «Принять к сведению» (напр. «Срок первого отчёта») |

`addCard.delay`: `{cards: N}` — через N карт (без `delay` — следующей картой); `{interludes: N}` — обязательно в интерлюдию «текущая + N»; `{interludes: 0}` — в конец текущей.

## Устройство

- `src/engine/` — чистый движок без UI: типы, валидация импорта, условия и эффекты, кризисы, эскалация, автосборка, итоги, публичная проекция (`public.ts`), экспорт журнала в Markdown. Все правила покрыты тестами в `engine.test.ts`.
- `src/store.ts` — единый стор: колода + состояние + стек истории для undo, автосохранение.
- `src/ui/PlayerScreen.tsx` — экран игроков. Принимает **только** `PublicState`: флагов, заметок, эффектов и пула в нём нет даже в памяти компонента.
- `src/ui/gm/` — пульт, сцены, итоги, журнал, колода, настройки.

## Что не входит в MVP

Визуальный редактор карт (сейчас есть просмотр, предпросмотр глазами игроков и импорт/экспорт JSON). Сетевой двухэкранный режим с сервером: сейчас второе окно работает только на том же устройстве через BroadcastChannel. Голосование игроков, звук.
